# AI Data Analysis Project

## Overview
This project demonstrates how to analyze real-world data using Python, apply data cleaning techniques, and build a simple machine learning model for prediction.

## Objective
To explore a dataset, identify patterns, clean the data, and extract meaningful insights, then use a machine learning model to predict outcomes.

## Tools Used
- Python
- Pandas
- Matplotlib
- Scikit-learn

## What I Did
- Loaded and explored a real-world dataset
- Cleaned the data by removing missing and unrealistic values
- Converted time data into numerical format for analysis
- Performed statistical analysis and correlation
- Visualized data using histograms, scatter plots, and line charts
- Built a Linear Regression model to understand the relationship between time and pulse
- Generated predictions based on the trained model
- Visualized the regression line to evaluate model performance

## Key Insight
The analysis showed a general positive relationship between time and pulse, but with high variability, indicating that additional factors may influence pulse rate.

## Outcome
This project demonstrates my ability to work with data, apply cleaning techniques, build machine learning models, and interpret results to draw meaningful conclusions.
